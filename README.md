# Investment Growth Simulator

## 📌 Overview
This project is a simple **Python simulation of compound interest**.  
It calculates how many years it takes for an initial investment to reach a target capitalization goal under different annual interest rates.  
The script demonstrates the use of **loops, conditionals, and mathematical modeling** in finance.

---

## 🧮 Features
- Calculate years required to double an investment at a fixed interest rate.
- Experiment with different interest rates to see how the timeline shifts.
- Loop through a range of interest rates (2%–8%) to compare outcomes.
- Demonstrates both **while loops** and **for loops** for iterative calculations.
